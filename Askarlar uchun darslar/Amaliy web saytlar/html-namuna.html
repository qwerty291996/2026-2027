Kurs haqida

Nimalarni o'rganasiz?

Bu kursda siz HTML yordamida sahifa tuzilishini, CSS yordamida dizaynni va JavaScript yordamida interaktivlikni o'rganasiz. Har bir dars amaliy topshiriq bilan yakunlanadi.

Birinchi darsdayoq <h1>Salom, dunyo!</h1> kodini yozib, natijani brauzerda ko'rasiz. Kurs davomida CSS va HTML bo'yicha rasmiy hujjatlar bilan ishlashni ham o'rganamiz - masalan, MDN sayti orqali.

Dasturlashni o'rganishning eng yaxshi usuli - kod yozishdir.

Eslatma: kurs boshlang'ich darajaga mo'ljallangan, oldindan bilim talab qilinmaydi.

Kurs bosqichlari

  1. HTML: sahifa tuzilishi va teglar
  2. CSS: ranglar, shriftlar, joylashuv
  3. JavaScript: hodisalar va dinamika
  4. Yakuniy loyiha: shaxsiy portfolio sayt
